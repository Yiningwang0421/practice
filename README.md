# Computer Engineering Practice

Practice repository for improving:

- C++
- Verilog / SystemVerilog RTL
- Digital Verification

## Workflow

1. Read the problem.
2. Solve it independently.
3. Commit and push.
4. Tell ChatGPT: `Judge 001`.
5. ChatGPT reviews the latest submission using hidden tests and edge cases.

Default judging mode:
Hints and counterexamples first. Full solution only when requested.

## Tracks

### C++
Algorithms, STL, memory, bit manipulation, debugging,
systems programming, and implementation.

### RTL
Combinational logic, sequential logic, FSMs, FIFOs,
pipelines, arbiters, handshakes, and datapaths.

### Digital Verification
Testbenches, assertions, scoreboards, random testing,
functional coverage, protocol verification, and DUT debugging.
